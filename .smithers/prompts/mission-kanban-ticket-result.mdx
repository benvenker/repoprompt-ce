# Synthesize Ticket Result

Summarize the final per-ticket loop outcome for downstream integration.

Classify status as:

- `completed` when implementation is present, validation passed, and review approved.
- `partial` when useful work exists but validation or review has unresolved issues.
- `failed` when no usable implementation exists or the branch should not be integrated.
